# ColdChainMonitoring-Demo
Interactive demo of a cold chain shipment tracking and environmental monitoring system.

## Repository Purpose

This repository is intended to host the public interactive demonstration of the Cold Chain Monitoring system.

- **Live Demo:** [Cold Chain Monitoring](https://haleyhsieh.github.io/ColdChainMonitoring-Demo/)
- **Development Repository:** ColdChainMonitoring-Integration (Private)
- **Deployment Status:** Pending initial deployment

The complete development source code, technical documentation, and development history are maintained in a separate private repository.

This public repository is intended to contain only approved production build artifacts for demonstration purposes.

本儲存庫僅供公開作品展示與操作體驗。完整開發原始碼、技術文件及版本紀錄皆維護於獨立的私人開發儲存庫。
